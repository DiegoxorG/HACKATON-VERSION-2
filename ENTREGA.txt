📈 FLUJO TÍPICO DE USO

1. ADMINISTRADOR ENTRA
   → Login con credenciales mock
   → Ve Dashboard con portafolio summary

2. IDENTIFICA URGENTES
   → Dashboard: "2 clientes crítico"
   → Click en cada uno
   → Lee reporte IA automático

3. CONTACTA CLIENTES
   → Detalle cliente: botón tel://
   → Guarda notas privadas
   → Hace seguimiento

4. CONSULTA IA
   → IA Analyst: "¿patrones preocupantes?"
   → Lee recomendaciones
   → Actúa basado en insight

5. GENERA REPORTES
   → Reportes: Selecciona tipo
   → Genera con IA
   → Descarga para ejecutivos
