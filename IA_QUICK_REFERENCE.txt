🔑 Si Quieres Usar Claude REAL

PASO 1: Obtener API Key (5 min)
────────────────────────────────
1. Ir a: https://console.anthropic.com/
2. Crear cuenta (gratis)
3. API Keys → Create Key
4. Copiar clave (ej: sk-ant-abcd...)

PASO 2: Guardar en Backend (seguro)
─────────────────────────────────────
Crear archivo: backend/.env

    ANTHROPIC_API_KEY=sk-ant-abcd...
    FLASK_ENV=development
    PORT=8000

PASO 3: Configurar Backend (Python)
────────────────────────────────────
from anthropic import Anthropic
import os

api_key = os.getenv("ANTHROPIC_API_KEY")
client = Anthropic()

@app.post("/api/chat")
def chat(message, system_prompt):
    response = client.messages.create(
        model="claude-3-5-sonnet-20241022",
        system=system_prompt,
        messages=[{"role": "user", "content": message}]
    )
    return response.content[0].text

PASO 4: Frontend Llama Backend
───────────────────────────────
// Frontend NO tiene key (seguro)
const response = await fetch('http://localhost:8000/api/chat', {
    method: 'POST',
    body: JSON.stringify({ message, system_prompt })
});
